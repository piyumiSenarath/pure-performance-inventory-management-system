# pure-performance-inventory-management-system
Inventory management system for Pure Performance Honda spare parts shop

📌 Project Overview
PURE PERFORMANCE Inventory Management System is a project developed to manage Honda spare parts inventory.

The system is being developed to organize spare parts information, categories, suppliers, and customers in a structured database.

🎯 Project Objectives
    - Maintain spare parts information.
    - Organize parts into categories.
    -Store supplier and customer information.
    - Track spare parts quantities.
    - Build a foundation for a complete inventory management application.

🛠️ Technologies Used
    - PostgreSQL 17
    - SQL
    - pgAdmin
    - Git
    - GitHub

📊 Current Progress
- Created the initial database tables.
- Added seven spare parts categories.
- Imported 367 Honda Civic EK3 spare parts.
- Verified the imported records and checked for duplicate part numbers.
- Added the parts CSV data to the GitHub repository.

🗄️ Database Tables
The database currently contains the following tables:
_____________________________________________
|__Table___|___________Purpose______________|
| category | Stores spare parts categories  |
| supplier | Stores supplier information    |
| customer | Stores customer information    |
| part     | Stores spare parts information |
|__________|________________________________|
